Por trás do GameZone

Um protótipo acadêmico de loja gamer desenvolvido a partir da proposta do Grupo 1, do curso de Análise e Desenvolvimento de Sistemas da FAMETRO.

Tecnologia com propósito

HTML, CSS e JavaScript conectam um catálogo JSON à pesquisa por texto, filtros, voz e carrinho demonstrativo. Os produtos também têm representação semântica em JSON-LD (Product e Offer).

Equipe da proposta

  • Ana Paula Vieira Lopes
  • Gracieide Guimarães Barbosa

  • Luiz Eduardo Custódio Duarte

Ilustrações e especificações demonstrativas. O cadastro fica no servidor Java quando usado em localhost ou no navegador no HTML offline. Os dados da compra ficam no navegador. Não há pagamentos nem conexão com estoque real.

Sua primeira partida

  1. Entre. Crie seu usuário e senha no primeiro acesso. Nos próximos acessos, entre com suas credenciais; a versão offline usa o mesmo navegador.
  2. Explore. Digite um produto, selecione a categoria ou ordene por preço. Os mesmos comandos de voz também podem ser digitados.
  3. Monte seu setup. Adicione itens ao carrinho, ajuste a quantidade e preencha os dados do comprador para concluir uma simulação sem cobrança.
  4. Continue depois. O carrinho é salvo neste navegador quando o armazenamento local está disponível.

Funciona sem internet

No HTML portátil, catálogo, ilustrações, pesquisa digitada, filtros e carrinho funcionam sem servidor. O recurso de voz é opcional e depende do navegador.

O salvamento automático depende das permissões do navegador. Mover o HTML, usar outro navegador ou limpar os dados pode remover o estado local. Ao limpar os dados do navegador, seu carrinho poderá ser perdido.
